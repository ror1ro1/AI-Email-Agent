# AI Email Agent

An automated, intelligent email processing and response automation agent built with Python. The system analyzes raw incoming corporate emails, evaluates sentiment, determines target intent, and dynamically generates structured, contextual response drafts.

## Features
- **Intent Detection & Routing**: Automatically classifies emails into categories (Sales, Technical Support, General Enquiry) and designates internal routing.
- **Sentiment Analysis**: Evaluates emotional tone to prioritize urgent or critical client issues.
- **Automated Drafting**: Utilizes Google Gemini 2.5 Flash API with strict JSON schemas to guarantee deterministic, production-ready system integrations.

## Tech Stack
- **Language**: Python 3
- **Core Orchestration**: Google GenAI SDK (Gemini 2.5 Flash)
- **Data Schema**: JSON Structured Outputs
